# Assets

La experiencia actual usa ilustraciones CSS (discos de vinilo y detalles decorativos) para mantener el sitio ligero y evitar imágenes externas con licencias dudosas.

Si más adelante añades fotografías, usa archivos propios o recursos con licencia adecuada. Guarda aquí los archivos y enlázalos con rutas relativas, por ejemplo `assets/foto.jpg`.
